# ✨ Live Text Analyzer

My first real-time text analyzer built with HTML, CSS & JavaScript.

## 🚀 Features

- 📝 **Word Counter** - Counts every word instantly
- 🔤 **Character Counter** - Track all characters including spaces
- 📖 **Sentence Detector** - Automatically detects sentences
- ⏱️ **Reading Time** - Calculates estimated reading time

## 💻 Technologies Used

- HTML5
- CSS3 (with animations & gradients)
- Vanilla JavaScript

## 🎨 Design

- Dark theme with neon glows
- Responsive design (works on mobile & desktop)
- Smooth animations & transitions
- Professional UI/UX

## 📖 How to Use

1. Open `index.html` in your browser
2. Go to "Analyzer" page
3. Type or paste your text
4. Watch your stats update in real-time!
